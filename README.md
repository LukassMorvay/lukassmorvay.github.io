# Lukáš Morvay — Portfolio Website

My personal portfolio site, built to showcase my education, work experience, and university projects.

🔗 **Live site:** [lukassmorvay.github.io](https://lukassmorvay.github.io/)

## About

This is a single-page portfolio for Lukáš Morvay — IT Developer and MSc Business Informatics student at Utrecht University (Cum Laude BSc graduate, University of Twente). It covers my background, education, work experience, projects, and skills, and includes contact links.

## Features

- Fully responsive design (desktop, tablet, and mobile)
- Dark / light theme toggle with saved preference
- Smooth scroll navigation with active-section highlighting
- Animated timeline for education and work experience
- Project showcase with tech stack tags
- Skill bars with progress animation
- Mobile-friendly hamburger navigation

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries)
- Vanilla JavaScript (no frameworks/libraries)
